# OIBSIP — Data Science Internship Projects (Oasis Infobyte) 🐍📊

## 📌 Overview
This repository contains 8 data science and machine learning projects completed during my **Data Science Internship at Oasis Infobyte**. The projects span two levels — from exploratory data analysis and data cleaning to predictive modeling and classification — using Python, Pandas, and Scikit-learn.

## 🛠️ Tools & Skills Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Scikit-learn (Machine Learning models)
- Jupyter Notebook
- Exploratory Data Analysis (EDA), Data Cleaning, Feature Engineering
- Classification & Regression Models

## 📂 Projects

| Level | # | Project | Description |
|-------|---|---------|-------------|
| Level 1 | 1 | Exploratory Data Analysis | Performed EDA to uncover patterns and trends in the dataset |
| Level 1 | 2 | Customer Segmentation | Segmented customers based on behavior using clustering techniques |
| Level 1 | 3 | Data Cleaning (NYC dataset) | Cleaned and preprocessed a real-world messy dataset |
| Level 1 | 4 | Sentiment Analysis (Twitter) | Built a model to classify tweet sentiment as positive/negative/neutral |
| Level 2 | 1 | Predicting House Prices | Built a regression model to predict house prices based on features |
| Level 2 | 2 | Wine Quality Prediction | Built a classification model to predict wine quality from chemical properties |
| Level 2 | 3 | Fraud Detection | Built a model to detect fraudulent transactions |
| Level 2 | 4 | Unveiling Android App Market | Analyzed Android app market data to derive business insights |

## 💡 Key Learnings
- Hands-on experience with the complete data science workflow — from raw data to model deployment-ready insights
- Applied multiple ML techniques: regression, classification, and clustering
- Strengthened skills in data cleaning, feature engineering, and model evaluation

## 🔗 How to Use
Each `.ipynb` file is self-contained — open in Jupyter Notebook/Google Colab and run cell-by-cell to reproduce the analysis.
